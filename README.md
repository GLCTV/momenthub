# MomentHub

Aplicație web pentru evenimente (nuntă, botez, aniversare, petrecere, gală): ce momente să prinzi, ce cadre și poziții să folosești, cu exemple reale. Română și engleză.

© 2026 GLC_TV. Toate drepturile rezervate.

## Fișiere

- `index.html` – toată aplicația (o singură pagină)
- `shots/`, `moments/`, `poses/` – pozele-exemplu
- `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` – pentru „Adaugă pe ecranul principal”
